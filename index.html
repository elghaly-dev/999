Honest limits

  • This protects against remote hackers only.
  • It does NOT protect against people on the same Wi-Fi.
  • Apps can still send saved data when internet returns — do not turn internet back on while sensitive apps are open.
  • A nearby radio attacker is a different problem from an internet hack.
